# FiscalQuest 🎯

**Gamified financial literacy for teens and young adults.**

FiscalQuest turns learning about money into a game. Instead of dry articles, users level up through interactive modules, earn XP, keep daily streaks, and use real financial calculators — all in one clean, fast web app.

### 🔗 Live Demo
**[https://bu44ito.github.io/Fiscal-Quest/](https://bu44ito.github.io/Fiscal-Quest/)**

*(No install needed — it runs right in your browser.)*

---

## Why it exists

Most people never get taught the basics of money in a way that sticks. FiscalQuest fixes that by making financial literacy interactive and rewarding: you learn by doing, you see your progress, and the concepts connect to real tools you'd actually use — budgeting, credit, mortgages, and investing.

## Features

- **Gamified learning** — earn XP, level up, and keep daily streaks as you complete lessons.
- **Learning modules** — bite-sized lessons across topics like Banking Basics, Budgeting, Credit Scores, Investing, Homeownership, and Taxes.
- **Financial tools** — working calculators built right in:
  - Budget Calculator (50/30/20 rule)
  - Mortgage Estimator (monthly payment & total interest)
  - Compound Interest projector
  - Credit Utilization checker
  - Emergency Fund planner
  - Debt Payoff (avalanche vs. snowball)
- **AI Coach** — ask money questions in plain English and get a straight answer.
- **Glossary** — plain-language definitions of key financial terms.
- **Daily Challenge** — a fresh task each day to build the habit.
- **Achievements** — unlock badges like *Budget Boss*, *Credit Wizard*, and *Homeowner IQ* as you progress.

## Tech

- Single-file web app — pure **HTML, CSS, and JavaScript**, no frameworks or build step.
- Fully responsive (works on phone and desktop).
- Zero dependencies beyond Google Fonts, so it loads fast and runs anywhere.

## Run it locally

No setup required. Either:

1. Open the live demo link above, **or**
2. Download `index.html` and double-click it to open in any browser.
